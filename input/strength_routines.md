# BAZA TRENINGÓW SIŁOWYCH (ROUTINES)
* **Zapis tempa**: Cztery cyfry oznaczają kolejno: faza ekscentryczna (opuszczanie) - pauza w rozciągnięciu - faza koncentryczna (unoszenie/skurcz) - pauza w skurczu.

## 1. ROUTINE: FBW (Full Body Workout)
1. **Bulgarian Split Squat (Dumbbell)**: 3 Serie, 10-12 powtórzeń, Tempo 3-0-1-0
2. **[SUPERSET] Góra ciała (Push & Pull)**:
* **A1: Incline Bench Press (Barbell)** 3 Serie, 8-10 powtórzeń
* **A2: Pull Up** 3 Serie, 8-10 powtórzeń,  Tempo 2-0-1-1
3. **Bent Over Row (Barbell)**: 3 serie, 8-10 powótrzeń, Tempo 2-0-1-1
4. **Single Leg Romanian Deadlift (Dumbbell)**: 2 seire, 10-12 powtórzeń, tempo 3-0-1-0
5. **Single Leg Hip Thrust (Dumbbell)**: 2 serie, 10-12 powtórzeń, tempo 2-0-1-1
6. **Single Leg Standing Calf Raise (Barbell)**: 3 serie, 10-12 powtórzeń, tempo 3-2-1-0
7. **Dead Bug**: 3 serie, 12-15 powótrzeń
8. **Side plank with leg raise**: 3 serie, 10-12 powótrzeń

## 2. ROUTINE: UPPER 
1. **Bench Press (Barbell)**: 3 serie, 8-10 powtórzeń, tempo 3-0-1-0
2. **Lat Pulldown (Cable)**: 3 serie, 8-10 powtórzeń, tempo 1-1-2-0
3. **Overhead Press (Barbell)**: 3 serie, 8-10 powtórzeń, tempo 2-0-1-1
4. **Seated Cable Row - Bar Grip**: 3 serie, 8-10 powtórzeń, tempo 2-1-1-1
5. **Seated Calf Raise**: 3 serie 10-12 powtórzeń, tempo 3-2-1-0
6. **[SUPERSET] Ramiona**:
* **A1: Bicep Curl (Barbell)**: 3 serie, 10-12 powtórzeń
* **A2: Triceps Pushdown**: 3 serie, 10-12 powtórzeń
7. **Cable Core Pallof Press**: 3 serie, 10-12 powtórzeń
8. **Ab Wheel**: 3 series, 10-12 powtórzeń
